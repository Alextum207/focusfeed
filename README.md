# FocusFeed

Private iPhone app: Instagram + YouTube without Shorts / Reels feed / Explore grid.
Built on GitHub Actions (no Mac needed), sideloaded with Sideloadly (no App Store).

## Install (once)

PC (Windows):
- iTunes and iCloud from **apple.com** (not the Microsoft Store versions)
- Sideloadly (sideloadly.io)
- USB cable, Apple ID (free)

iPhone:
- Trust this computer when plugged in
- Settings > Privacy & Security > Developer Mode > on (appears after first sideload attempt), restart
- After install: Settings > General > VPN & Device Management > your Apple ID > Trust

## Get the app

1. GitHub > Actions > latest run > artifact `FocusFeed-ipa` > unzip
2. Sideloadly: drag `FocusFeed.ipa`, enter Apple ID, Start
3. Free Apple ID: app expires after 7 days; re-run step 2 with the same IPA.
