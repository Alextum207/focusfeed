# FocusFeed

Eine iPhone-App für Instagram und YouTube, ohne Algorithmus-Falle.

- **Am Anfang** gibst du ein, was du sehen willst (z. B. `motivation, gaming`) und wie lange (1 bis 90 Minuten).
- **YouTube** zeigt dir nur Videos zu deinen Begriffen. Keine Startseite, keine Empfehlungen, keine Shorts.
- **Instagram** zeigt dir nur Beiträge, Storys und Nachrichten von Leuten, denen du folgst. Keine Reels und keine Vorschläge. Was du schon gesehen hast oder was älter als 7 Tage ist, wird ausgeblendet.
- **Ist deine Zeit um,** ist die App gesperrt: 4-mal so lange, wie du sie benutzt hast.

**Das brauchst du in jedem Fall:**
- dein iPhone
- das **Ladekabel** vom iPhone (zum Verbinden mit dem Computer)
- eine **Apple-ID**, also die E-Mail und das Passwort, mit denen du dich im App Store anmeldest
- die Datei **`FocusFeed.ipa`**: Die bekommst du von Alex, z. B. per Mail oder USB-Stick. Speichere sie in deinem **Downloads**-Ordner.

Du brauchst etwa **20 Minuten**, nur beim ersten Mal.

## Windows + iPhone

### Teil 1: Programme auf dem Computer installieren

Das machst du nur ein einziges Mal.

**Schritt 1: Prüfen, ob schon iTunes oder iCloud drauf ist**
1. Unten links auf das **Windows-Symbol** (Start) klicken.
2. **Apps** eintippen und auf **„Installierte Apps“** (oder „Apps & Features“) klicken.
3. Oben in das Suchfeld **iTunes** eintippen.
4. Ist iTunes da: rechts auf die **drei Punkte** (bzw. darauf klicken) → **Deinstallieren** → bestätigen.
5. Dasselbe mit **iCloud** machen.

> Warum? Die iTunes- und iCloud-Versionen aus dem Microsoft Store funktionieren nicht. Du brauchst die Versionen direkt von Apple, siehe Schritt 2.

**Schritt 2: Sideloadly, iTunes und iCloud installieren**
1. Den Browser öffnen (Chrome, Edge …).
2. Oben in die Adresszeile **sideloadly.io** eintippen und Enter drücken.
3. Auf der Seite den Bereich **Download** suchen.
4. Dort auf den Download für **Windows** klicken. Die Datei wird heruntergeladen.
5. Auf derselben Seite stehen auch Links zu **iTunes** und **iCloud** (die richtigen Versionen von Apple). Beide anklicken und herunterladen. Bei iTunes die **64-Bit**-Version nehmen.
6. Den **Downloads**-Ordner öffnen. Das geht unten in der Taskleiste über das gelbe Ordner-Symbol, dann links auf **Downloads**.
7. Zuerst die **iTunes**-Datei doppelklicken und einfach immer auf **Weiter** / **Installieren** klicken.
8. Dann die **iCloud**-Datei genauso installieren. Falls iCloud nach einer Anmeldung fragt, kannst du das Fenster einfach schließen.
9. Dann die **Sideloadly**-Datei genauso installieren.
10. Falls der Computer einen **Neustart** möchte: ja, neu starten.

### Teil 2: iPhone mit dem Computer verbinden

1. iPhone mit dem **Ladekabel** an den Computer anschließen.
2. iPhone **entsperren** (Code eingeben).
3. Auf dem iPhone erscheint: **„Diesem Computer vertrauen?“** → auf **Vertrauen** tippen → iPhone-Code eingeben.
   Kommt die Frage nicht, Kabel abziehen und wieder einstecken.

### Teil 3: Die App aufs iPhone bringen

1. **Sideloadly** öffnen (Start-Menü → „Sideloadly“ eintippen → anklicken).
2. Den **Downloads**-Ordner öffnen, sodass du die Datei **`FocusFeed.ipa`** siehst.
3. Die Datei **`FocusFeed.ipa`** mit der Maus **in das Sideloadly-Fenster ziehen** und loslassen. Sie erscheint dann oben im Feld (dem großen Symbol links).
4. Im Feld für das Gerät (**iDevice**) muss dein iPhone stehen. Falls nicht: das Feld anklicken und dein iPhone auswählen.
5. Im Feld **Apple account** deine **Apple-ID-E-Mail** eintragen.
6. Auf **Start** klicken.
7. Es kommt ein Fenster für das **Passwort** deiner Apple-ID → eintippen → **OK**.
8. Wenn du einen **Code** auf dein iPhone oder per SMS bekommst: diesen Code in Sideloadly eintippen → **OK**.
9. Warten. Unten steht, was gerade passiert. Wenn **„Done.“** erscheint, bist du fertig.

👉 Jetzt weiter mit [Auf dem iPhone freischalten](#auf-dem-iphone-freischalten).

## Mac + iPhone

### Teil 1: Sideloadly installieren

Das machst du nur ein einziges Mal. iTunes brauchst du auf dem Mac **nicht**.

1. **Safari** öffnen.
2. Oben in die Adresszeile **sideloadly.io** eintippen und Enter drücken.
3. Auf der Seite den Bereich **Download** suchen und auf den Download für **macOS** klicken.
4. Unten im Dock auf **Downloads** (oder im Finder links auf **Downloads**) klicken und die Sideloadly-Datei doppelklicken.
5. Im Fenster das **Sideloadly-Symbol** auf den Ordner **Programme** (Applications) ziehen.
6. Den **Finder** öffnen → links **Programme** → **Sideloadly** doppelklicken.
7. Kommt die Meldung „kann nicht geöffnet werden, da sie von einem nicht verifizierten Entwickler stammt“:
   - Oben links auf das **Apple-Symbol** → **Systemeinstellungen** → **Datenschutz & Sicherheit**.
   - Ganz nach unten scrollen → bei Sideloadly auf **Trotzdem öffnen** klicken → Mac-Passwort eingeben.

### Teil 2: iPhone mit dem Mac verbinden

1. iPhone mit dem **Ladekabel** an den Mac anschließen.
2. iPhone **entsperren**.
3. Auf dem iPhone erscheint **„Diesem Computer vertrauen?“** → **Vertrauen** → iPhone-Code eingeben.
4. Fragt der Mac „Zubehör erlauben?“ → **Erlauben**.

### Teil 3: Die App aufs iPhone bringen

1. **Sideloadly** öffnen.
2. Den **Finder** öffnen → links **Downloads**, sodass du **`FocusFeed.ipa`** siehst.
3. Die Datei **`FocusFeed.ipa`** **in das Sideloadly-Fenster ziehen**.
4. Im Feld **iDevice** muss dein iPhone stehen. Falls nicht: anklicken und auswählen.
5. Im Feld **Apple account** deine **Apple-ID-E-Mail** eintragen.
6. Auf **Start** klicken.
7. **Passwort** deiner Apple-ID eingeben → **OK**.
8. Kommt ein **Code** auf dein iPhone oder per SMS: eintippen → **OK**.
9. Warten, bis **„Done.“** erscheint.

👉 Jetzt weiter mit [Auf dem iPhone freischalten](#auf-dem-iphone-freischalten).

## Auf dem iPhone freischalten

Das musst du nur beim ersten Mal machen, egal ob du Windows oder Mac hast.

**Schritt 1: Entwicklermodus einschalten**
1. Auf dem iPhone die App **Einstellungen** (graues Zahnrad) öffnen.
2. Nach unten scrollen → **Datenschutz & Sicherheit** antippen.
3. Ganz nach unten scrollen → **Entwicklermodus** antippen.
4. Den Schalter **einschalten** (grün).
5. Das iPhone fragt nach einem Neustart → **Neustart** antippen.
6. Nach dem Neustart kommt die Frage „Entwicklermodus aktivieren?“ → **Aktivieren** antippen → iPhone-Code eingeben.

> Siehst du „Entwicklermodus“ nicht? Dann mach erst Teil 3 oben fertig. Der Punkt erscheint erst, nachdem die App einmal installiert wurde.

**Schritt 2: Der App vertrauen**
1. **Einstellungen** öffnen.
2. **Allgemein** antippen.
3. Nach unten scrollen → **VPN & Geräteverwaltung** antippen.
4. Unter „Entwickler-App“ deine **E-Mail-Adresse** antippen.
5. **„… vertrauen“** antippen → nochmal **Vertrauen** bestätigen.

**Schritt 3: Loslegen**
1. Auf dem Home-Bildschirm die App **FocusFeed** antippen.
2. Unten auf **Instagram** tippen und dich mit deinem Instagram-Konto **anmelden**.
3. Unten auf **YouTube** tippen und dich mit deinem Google-Konto **anmelden** (optional).
4. Fertig! 🎉

## Wichtig: Alle 7 Tage neu installieren

Mit einer normalen (kostenlosen) Apple-ID **hört die App nach 7 Tagen auf zu funktionieren**. Sie öffnet sich dann nicht mehr.

So bringst du sie wieder zum Laufen:
1. iPhone wieder per Kabel an den Computer anschließen.
2. Sideloadly öffnen.
3. **`FocusFeed.ipa`** wieder hineinziehen → **Start** → Passwort eingeben → warten bis **„Done.“**.

Freischalten musst du dann nichts mehr. Deine Logins bleiben normalerweise erhalten.

## Android

**Geht leider nicht.** FocusFeed gibt es nur fürs iPhone. Die Datei `FocusFeed.ipa` lässt sich auf Android-Handys nicht installieren. Dafür müsste die App komplett neu für Android gebaut werden.

## Für Entwickler

- Code in `Sources/`, Tests in `Tests/`. Das Xcode-Projekt wird mit `xcodegen` aus `project.yml` erzeugt.
- Jeder Push baut und testet auf GitHub Actions (`.github/workflows/build.yml`). Die IPA liegt dort als Artifact **`FocusFeed-ipa`**:
  `gh run download -R Alextum207/focusfeed -n FocusFeed-ipa`
- **Direkt auf dem Mac bauen** statt Sideloadly: Xcode installieren, dann
  ```sh
  brew install xcodegen
  git clone https://github.com/Alextum207/focusfeed.git && cd focusfeed
  xcodegen && open FocusFeed.xcodeproj
  ```
  Unter **Signing & Capabilities** dein Team (Apple-ID) wählen, falls nötig eine eigene Bundle-ID setzen, iPhone als Ziel auswählen → **▶ Run**.
- Debug: In der App auf den **schon ausgewählten Tab** tippen. Dann erscheint eine Zeile mit Pfad und Diagnosewerten.
